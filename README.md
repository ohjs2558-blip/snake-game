# 지렁이 게임 (Snake Game)

웹 브라우저에서 바로 실행할 수 있는 클래식 지렁이(스네이크) 게임입니다.

## 🎮 게임 특징
- **간단한 실행**: 별도의 설치 없이 브라우저에서 `index.html`을 열면 즉시 플레이 가능합니다.
- **점수 기록**: 최고 점수가 브라우저(`localStorage`)에 저장됩니다.
- **다양한 조작 방식**: 키보드 및 화면 하단 터치/마우스 버튼을 모두 지원합니다.

## 🕹️ 조작 방법
- **이동**: 방향키 (`↑`, `↓`, `←`, `→`) 또는 `W`, `A`, `S`, `D`
- **일시정지 / 재개**: `스페이스바 (Space)`
- **모바일/터치**: 화면 아래의 방향 화살표 버튼 클릭

## 📁 파일 구조
- `index.html`: 게임 실행에 필요한 HTML, CSS, JavaScript가 모두 포함된 단일 파일
- `README.md`: 프로젝트 소개 및 사용 가이드
- `.gitignore`: Git 버전 관리 제외 설정 파일
